---
title: "List Conversation Feedback"
api: "GET /conversations/feedback"
description: "List feedback on your Uservox conversations, from the API and the dashboard, with its review status and the Uservox team's response. Filters and pagination."
---

Lists feedback on your project's conversations, newest first. The list includes feedback given through [Submit Conversation Feedback](/api-reference/submit-conversation-feedback) and with **Give Feedback** in the dashboard. Use it to check whether feedback has been reviewed and to read the response.

## Query Parameters

<ParamField query="conversationId" type="string">
  Only return feedback on this conversation.
</ParamField>

<ParamField query="status" type="string">
  Only return feedback with this status. One of `open`, `addressed`, `addressed_backend`, `model_issue`, `acknowledged`, `acknowledged_unfixable`. See [Status values](#status-values).
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number, starting at 1.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Results per page, at most 200.
</ParamField>

## Status values

| Status | Meaning |
|--------|---------|
| `open` | Not reviewed yet |
| `addressed` | Fixed. `simulatedConversationLink` shows the fix. |
| `addressed_backend` | Fixed in the backend |
| `model_issue` | Caused by the underlying AI model |
| `acknowledged` | Noted |
| `acknowledged_unfixable` | Noted. Everything possible has been done, but it cannot be fully fixed. |

## Error Responses

- **400 Bad Request**: `status` is not one of the values above.
- **401 Unauthorized**: the API token is missing or invalid.
- **500 Internal Server Error**: `{ "success": false, "error": "Failed to list feedback" }`
