## Overview

Uservox integrates with your CRM to read and write lead/contact data, log call outcomes, and keep your pipeline up to date.

## CRM Integration Guide

The API integration guides cover:

- [Authentication](/api-integration/authentication) and [project details](/api-integration/project-details): API keys, Project ID and Process ID
- [Initiating a single lead](/api-integration/leads-initiate) or [leads in bulk](/api-integration/leads-bulk-initiate), with [field rules](/api-integration/field-validations) and [examples](/api-integration/examples)
- [Webhooks for call outcomes](/guides/process/how-to-add-webhook-to-a-process) and [example payloads](/api-reference/activity-payloads)
- The full [API reference](/api-reference/introduction)

## Common Scenarios

- Create/Upsert Lead from your CRM or website
- Sync agent-collected fields (budget, timeline, intent) to your CRM
- Receive webhooks for call outcomes to trigger workflows
- Book meetings via calendar integration and update CRM automatically

## Next Steps

- Obtain your API credentials from https://app.uservox.ai
- Map your CRM fields to Uservox agent capture fields
- Register a webhook endpoint to receive real-time events
