## One-click install

Uservox runs a remote [MCP](https://modelcontextprotocol.io) server at `https://mcp.uservox.ai/mcp`. It uses OAuth with PKCE and dynamic client registration, so there is no API key to copy — each client signs you in and asks for consent the first time.

If a browser blocks the custom link, use the raw links below, or add the server manually with the [JSON config](#any-other-client).

## Claude Code

```bash
claude mcp add --transport http uservox https://mcp.uservox.ai/mcp
```

Run `/mcp` inside the session and approve the consent screen in the browser tab that opens.

Or install it as a plugin, which registers the same server for you:

```text
/plugin marketplace add girnarai/uservox-mcp
/plugin install uservox-mcp@uservox
```


## Codex CLI

Add the server to `~/.codex/config.toml`:

```toml
[mcp_servers.uservox]
url = "https://mcp.uservox.ai/mcp"
```

Then sign in once:

```bash
codex mcp login uservox
```

## claude.ai and Claude Desktop

In claude.ai open **Settings → Connectors → Add custom connector**, paste `https://mcp.uservox.ai/mcp`, then click **Allow** on the consent screen.

For Claude Desktop, add the block below to `claude_desktop_config.json` and restart the app:

```json
{
  "mcpServers": {
    "uservox": {
      "type": "http",
      "url": "https://mcp.uservox.ai/mcp"
    }
  }
}
```

## ChatGPT

In ChatGPT open **Settings → Connectors → Advanced → Developer mode**, then **Add custom connector** and paste the same URL.

## Check the connection

Ask the client *"who am I on Uservox?"* — the `whoami` tool returns your workspace, tier, project access, and granted scopes without touching any data.

From a terminal, the server's auth challenge confirms it is reachable:

```bash
curl -sI https://mcp.uservox.ai/mcp | head -3
```

```text
HTTP/2 401
www-authenticate: Bearer realm="vox-mcp", error="missing_bearer",
  resource_metadata="https://mcp.uservox.ai/.well-known/oauth-protected-resource/mcp"
```

## What you can do once connected

- **Leads** — find, search, count, update, reset, or reschedule leads, and run an action across many at once.
- **Calls** — list conversations, read transcripts, summaries, and recordings by link.
- **Analytics** — funnel, cohort, and lead-flow reports for a date range.
- **Agents and processes** — read and edit prompts, variables, decisions, FAQ sets, and process steps.
- **WhatsApp** — list and create templates, inspect chats, set button routes.
- **Testing** — create and run agent test cases, and start simulated calls.

Tools are only listed when your token can call them: a read-only token never sees admin or billing tools.
